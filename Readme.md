# Indian Idly Cafe 🍃

A beautiful, responsive website template for an Indian Idly Cafe specializing in authentic South Indian cuisine, including idli, dosa, breakfast combos, and beverages.

## ✨ Features

- Modern forest-green and leaf-green design.
- Responsive layout for desktop, tablet, and mobile.
- Interactive food menu with category filters.
- Shopping cart with quantity controls and automatic total calculation.
- WhatsApp ordering interface.
- Smooth scrolling and scroll-reveal animations.
- About section, customer testimonials, and contact information.
- Bootstrap 5 integration and vanilla JavaScript functionality.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript
- Bootstrap Icons
- Google Fonts

## 🚀 Getting Started

1. Clone this repository.
2. Open `index.html` in your browser.
3. Customize the menu, prices, images, contact details, and WhatsApp number in the project files.

## 📌 Note

This project is a front-end website template. WhatsApp ordering requires configuration of the cafe's phone number. Online payments and backend order management are not included.

## 🎯 Purpose

Created as a modern restaurant website template to showcase South Indian cuisine and provide customers with an attractive, easy-to-use browsing and ordering experience.
